# Job files

Each estimate is a `JOB` object. `../proposal.html` reads `../job.js`.

- `_blank.js` — start here for a new job
- `PNP-2026-0817-danielle.js` — the design reference (Danielle interior)

To reprint a past job:

```bash
cp jobs/PNP-2026-0817-danielle.js job.js
open proposal.html
```

Numbering: `PNP-YYYY-MMDD`. Filename: `PNP-YYYY-MMDD-lastname.js`.
